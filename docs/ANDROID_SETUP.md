# Android App Setup

## Requirements
- Android Studio 4.0+
- Android SDK 8.0+ (API 26)
- Java JDK 11+

## Setup

1. Open Android Studio
2. Import `mobile/` project
3. Sync Gradle
4. Update API endpoint in `api/ApiClient.java`
5. Build and run

## Features
- Student login
- QR scanning
- Attendance submission
- History view
- Student registration
